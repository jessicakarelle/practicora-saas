# SEO

Le SEO concerne seulement les pages publiques de Practicora. Les espaces privés, les pages de connexion et les routes liées au compte ne doivent pas être indexés comme du contenu public.

## Ce qui est déjà prévu

- titres et descriptions par page;
- URL canoniques;
- variantes linguistiques;
- sitemap dynamique;
- `robots.txt`;
- manifeste;
- métadonnées Open Graph;
- image sociale générée;
- données structurées pour certains contenus;
- pages de guides et d’articles;
- navigation interne;
- HTML sémantique;
- prise en charge de `prefers-reduced-motion`;
- `noindex` sur les routes privées lorsque prévu.

## Avant de mettre le site en ligne

1. choisir le domaine final;
2. définir `NEXT_PUBLIC_SITE_URL`;
3. utiliser une vraie adresse dans `NEXT_PUBLIC_CONTACT_EMAIL`;
4. vérifier toutes les métadonnées sur le domaine final;
5. connecter Google Search Console et, si utile, Bing Webmaster Tools;
6. soumettre le sitemap;
7. vérifier les pages légales;
8. mesurer les Core Web Vitals en production;
9. publier du contenu original si le blog est réellement utilisé;
10. ajouter des redirections si d’anciennes URL ont déjà été partagées ou indexées.

Le fait d’avoir un sitemap et des métadonnées correctes ne garantit pas un classement précis dans les moteurs de recherche.
